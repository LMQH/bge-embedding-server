## 背景与使用场景

为知识库 / RAG 提供文本嵌入 API，兼顾文档入库与在线查询。接收中英文混合纯文本，调用方负责文件解析和文档切分。服务部署于内网，通过内网或 VPN 访问，用于日常使用；共享 API Key 为非生产用途。

暂无指定调用方，采用 OpenAI Embeddings 风格的基础接口。入库期间查询可有限等待，首版依次处理请求，不要求查询优先。并发、文本长度分布和入库规模暂无估计，不作为开工前置条件。

本机开发，在 Mac mini M4 16GB 验证与部署。用户确认两机局域网联通、目标机随时可访问；实际连接参数、目标系统和环境仍须在部署前核实。

## 首版范围与约束

首版交付一个轻量的原生 Python API、真实模型适配、必要异常处理、健康检查和 launchd 启动说明。语言、实现库、权重选择及虚拟环境规则见 ADR-0003；具体协议以 Spec 为准。

不引入文件解析、文档切分、向量数据库、检索业务、reranker、sparse / ColBERT 输出、管理页面、多模型调度或生产账号系统。API 批量输入可以在服务内逐条推理，不要求动态合批或模型并行执行。

先正确可用，再优化。当前不设延迟或吞吐硬指标，不以容量规划或性能基准作为开工条件。Spec 中有界保护值由实施侧依据 Q13 授权制定，是初始工程默认值，不是实测容量或性能承诺。
