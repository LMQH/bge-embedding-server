# ADR-0004：首版仅做基本服务冒烟

## 状态

已接受，2026-10-15。用户明确要求绕过不必要的官方参考验证，并进一步要求“不应当加重测试验收的范围，不应执行复杂的测试，一切从简”。

## 决策

首版使用现有 8bit 权重，完成服务部署，只保留模型加载、健康检查、鉴权、单条 / 小批量真实调用及项目环境核实。官方参考模型对照、完整边界 / 队列套件、压力测试、故障注入均不作为必做项，不为测试继续扩大范围。

本文替代 [ADR-0003](0003-native-python-runtime.md) 中强制参考验证的要求。API、输入限制、串行执行及原生部署方案不变。实际出现问题时针对问题修复，不预设额外评测项目。

## 后果

已执行结果保留为历史证据；未执行或取消的检查不报告为通过。仅凭基本冒烟不能声称所有极限场景已经验证。更新 [Spec](../specs/0001-embedding-inference.md) 与 [Plan](../plans/0002-minimal-service.md) 作为当前实施依据。
