## 范围

`POST /v1/embeddings` 的请求完成日志、请求内重复文本处理与过载响应头。不改变请求 / 响应字段、成功响应结构、错误码与错误消息、鉴权、长度与批量上限、队列容量、缓存键与淘汰策略。

## 输入、输出与行为

### 请求完成日志

现有日志前缀与字段保持不变，在行末追加四个非负整数字段：

```text
path=/v1/embeddings status=200 code=ok seconds=0.031 batch=3 tokens=9 hits=0 wait_ms=0 exec_ms=2 ahead=0 dedup=1
```

| 字段 | 含义 | 取值规则 |
| --- | --- | --- |
| wait_ms | 从成功入队到开始执行的毫秒数 | 已开始执行时按实际等待计；排队超时或等待中客户端断开时，按入队到请求结束计；无调度任务（全命中、校验失败、队列满）为 0 |
| exec_ms | 单次推理执行的毫秒数 | 已开始执行时按开始到结束计；未开始执行为 0 |
| ahead | 入队瞬间前方任务数（执行中 1 个 + 等待中） | 无调度任务为 0；第一个任务为 0 |
| dedup | 本请求内因重复而跳过推理的条目数 | 无重复为 0；只统计进入推理子批的重复项，已由缓存命中的条目不重复计入 |

- 四个字段均为 `time.monotonic()` 推导的观测值，不是 SLO、容量或延迟承诺；`seconds` 仍是请求级总耗时。
- 字段只包含计数与时长，不得包含输入正文、向量、Key、模型路径或异常原文。
- 字段追加在现有字段之后；不改变已有字段的名称、顺序与格式。

### 请求内去重

- 去重发生在鉴权、解析、完整校验、token 化与缓存查询之后；无效请求不进入去重。
- 判定键为 tokenizer 输出的完整 token id 序列；同一请求内 `return_sparse` 一致，因此不额外区分标志。
- 相同 token 序列的多个条目只提交一次推理；推理结果按原输入顺序映射回每个条目。
- 响应仍为每个输入一条，`index` 从 0 连续递增，`usage.prompt_tokens` / `total_tokens` 仍为全部输入（含重复项与缓存命中项）的 token 数之和。
- 缓存回填只针对去重后的唯一项；缓存键、容量估算、LRU 淘汰与 `return_sparse` 隔离规则不变。
- 去重只限单个请求内，不做跨请求合并；并发的相同文本仍各自按现有缓存与队列语义处理。
- 推理失败时整批失败，不返回部分结果；去重不引入新的错误码或降级路径。

### 过载响应头

- `429 queue_full` 与 `429 queue_timeout` 的响应增加 `Retry-After: 1`（秒）。
- 其他状态码与错误码不增加该响应头。
- 不改变 429 的 `message`、`type`、`param`、`code` 或触发条件；不新增重试计数、配额或限流。

## 约束

- 不新增配置项，配置总数保持 18 项；不新增运行时依赖、端点或后台任务。
- 单 worker、单模型串行、1 个执行位 + 19 个等待位、30 秒排队超时与既有请求上限均不变。
- 日志写入沿用现有轮转与安全过滤；新增字段不得绕过 `SafeServerLog` 的异常脱敏。
- 验证按 ADR-0004 保持最小：定向单元测试 + 真实服务冒烟；不恢复压力、故障注入或效果评测。

## 验收场景

| 场景 ID | 需求 ID | 前置条件与输入 | 预期结果 | 验证方式 |
| --- | --- | --- | --- | --- |
| AC-401 | REQ-025 | 单条未命中请求成功 | 日志含 `wait_ms`、`exec_ms`、`ahead`、`dedup`，均为非负整数；`ahead=0`、`dedup=0` | 单元测试 + 日志检查 |
| AC-402 | REQ-025 | 首个请求执行中，第二个请求排队后成功；另有一条排队超时 | 排队请求 `ahead>=1`；成功请求 `wait_ms>=0`、`exec_ms>=0`；超时请求 `exec_ms=0` 且 `wait_ms` 覆盖等待时间 | 单元测试 |
| AC-403 | REQ-026 | `["a","b","a"]`，缓存开启与关闭各一次 | 推理调用 2 次；响应 3 条且顺序正确；`usage` 按 3 条统计；缓存关闭时行为一致 | 单元测试 |
| AC-404 | REQ-027 | 触发 `queue_full`、`queue_timeout` 与一条 400 校验失败 | 两个 429 均带 `Retry-After: 1`；400 不带该头 | 单元测试 + 真实服务冒烟 |
| AC-405 | REQ-028 | 全量非 real 测试与配置加载 | 95 项既有测试继续通过；配置仍为 18 项；无新依赖 | 单元回归 |
| AC-406 | REQ-029 | 本机真实模型 HTTP 冒烟 | 成功与过载日志含四个新字段；429 带 `Retry-After`；日志不含正文、Key 或向量 | 真实服务冒烟 |
