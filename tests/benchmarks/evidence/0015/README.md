## 持续 30 分钟

2.25 rps 混合负载：4,050 / 4,050 成功，0 拒绝、0 丢发，5,498,112 tokens，**3,053.6 tokens/s**，P50 / P95 655 / 1,937 ms，排空 0.53 s。日志 4,050 条 `hits=0`、`dedup=0`，`max wait_ms=1,671`。RSS 489 → 522（峰值）→ 367 MiB，swap 全程 33.5 MiB。首尾 10 分钟吞吐 3,044 → 3,048 tokens/s；同类 P95 变化 ≤2%。

## 过载与恢复

| 检查 | 结果 |
| --- | --- |
| 24 × 32768 tokens 并发 | 2 成功（15.4 / 31.0 s），18 `queue_timeout`，4 `queue_full`，均 `Retry-After: 1`；服务端最大等待 30,001 ms |
| 等待中 / 执行中取消 | 日志 2 × 499；后续探测 200；无等待位泄漏 |
| 过载后正常负载 | 20/20 成功，P50 45 ms，P95 75 ms |
| SIGTERM | 执行中请求 200（15.7 s）；2 个等待请求 503 `model_unavailable`；新进程 2.59 s 就绪（自信号 17.59 s） |
| SIGKILL | launchd 拉起 9.99 s 就绪；探测 200 |
| 重启后冒烟 | `verify_http.py --launchd --sparse --long` 全 PASS（8192 tokens 3.68 s） |

重启后缓存为空，恢复探测为冷缓存。

## 判定与未覆盖

- 契约通过：无 5xx / 429 / 客户端超时，输出校验全通过，过载分类正确，拒绝与取消可恢复，两种停止方式均恢复。
- 容量只到首次拒绝点：短查询 40～80 rps、混合 ≥3 rps 干净；P95 目标未定义，不宣布 SLO 容量。
- 未覆盖：能耗、Metal 峰值、整机重启 / 登录、跨主机客户端。
- 所有数字为该负载下的观测值，不是承诺。
